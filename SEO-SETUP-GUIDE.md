# CSC Bir Sujra — Google Ranking Setup Guide

## Important truth
No developer or SEO agency can guarantee the number-one position. This website is technically optimized, but ranking also needs a verified business profile, real local reputation, backlinks, useful updates and time.

## 1. Domain
This build uses **https://cscbirsujra.in** in canonical tags and sitemap. Register/connect this exact domain, or replace it everywhere before deployment.

## 2. Google Business Profile — highest priority for local search
1. Create or claim the profile using the exact business name: **Shubham Saini CSC Center**.
2. Add the exact phone: **+91 70274 94674**.
3. Add the real pin/location and regular opening hours.
4. Upload original shop-front, signboard, inside-counter and owner/team photos. Stock photos should not be used as business-profile proof.
5. Add the deployed website URL.
6. Ask real customers for honest Google reviews; never buy or create fake reviews.

## 3. Google Search Console
1. Add the domain property.
2. Verify DNS ownership.
3. Submit: `https://cscbirsujra.in/sitemap.xml`
4. Inspect the home page and request indexing after deployment.

## 4. Replace stock media with real media
The included Pexels media makes the design premium, but authentic center photos and a short real video normally provide stronger trust and local relevance. Keep descriptive filenames such as `shubham-saini-csc-bir-sujra-shop-front.webp`.

## 5. NAP consistency
Use the same Name, Address and Phone on the website, Google Business Profile, Facebook/Instagram, Justdial and other genuine directories. Do not create fake addresses in nearby villages.

## 6. Content plan
Publish one genuinely useful guide every 1–2 weeks. Update old guides when portal rules change. Avoid copying official sites or generating dozens of low-value village pages.

## 7. Performance
Images are locally compressed WebP files. The Pexels video is remote and uses `preload=none`; replace it with a compressed local 720p WebM/MP4 when a real center video is available.

## 8. Before going live
- Confirm every listed service is actually offered or keep the availability disclaimer.
- Add real business hours.
- Add exact Google Maps business link after profile verification.
- Replace the domain in canonical/sitemap if using a different domain.
- Test structured data with Google Rich Results Test.
- Test mobile speed with PageSpeed Insights.
